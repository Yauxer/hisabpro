# HisabPro — sécurité des comptes et révocation des sessions

Les trois fiches SEC001 à SEC003 sont exécutées dans Edge sur ordinateur et mobile avec la véritable API et PostgreSQL natif isolé. Les réponses d'un ancien chargement ou d'un ancien jeton sont ignorées ; l'horloge et les écritures ne sont pas modifiées. Les appels explicites de mutation conservent leur rejet pour leur propre formulaire. Aucun droit serveur ni règle métier comptable n'est changé.

Les premiers échecs sont conservés : une attente de champ actif non exposé par auth/me est corrigée dans le test ; l'erreur réelle de calendrier est ensuite reproduite aux deux largeurs et corrigée.
