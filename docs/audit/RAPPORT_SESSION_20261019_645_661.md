# HisabPro — état de livraison645 à661

Les règlements disposent désormais d’un formulaire d’annulation avec date
modifiable et motif facultatif, pour une opération individuelle ou pour une
ventilation entière. Le lot collectif affiche son montant et tous ses numéros
avant confirmation. Les refus restent visibles et les listes se rafraîchissent
après succès. Les contrepassations restent à contrôler et valider au Journal ;
les originaux sont conservés.

Les travaux précédents de cette session ont fiabilisé les pièces jointes et
ajouté la consultation des documents d’OD RAS et de contrepassation dans les
registres et leurs exports. Un cahier Word/PDF/Excel complémentaire est livré,
avec douze cas humains et un oracle chiffré indépendant.
