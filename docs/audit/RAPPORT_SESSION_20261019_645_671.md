# HisabPro — livraisons645 à671, hors RH/paie

Les annulations de règlements disposent d’une date modifiable et d’un motif
facultatif, individuellement et pour une ventilation entière. Les erreurs de
lecture des règlements et réceptions sont visibles avec une reprise explicite ;
les anciennes réponses sont écartées. Les commandes des règlements sont
cohérentes avec la consultation seule. La préparation d’une réception passe
clairement par les commandes achat, avec une navigation mobile lisible.

Les travaux précédents ont fiabilisé les pièces jointes et ajouté les documents
d’OD RAS et de contrepassation dans les registres et exports. Le jeu principal
de recette RAS a été révisé, documenté et confronté à un oracle indépendant.
Aucun PostgreSQL réel ni donnée comptable réelle utilisé ou modifié.
